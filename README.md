Mecânica Solidária
Sobre o projeto

A Mecânica Solidária é um projeto de site para uma ONG que oferece apoio e serviços básicos de mecânica para pessoas da comunidade.

Objetivo

O objetivo do projeto é apresentar a ONG, seus serviços, projetos e formas de contato, utilizando uma interface simples e acessível.

Tecnologias utilizadas
HTML5
CSS3
JavaScript
